# 第2段階・星うさぎ初登場 確認記録

確認日：2026-10-21（日本時間）。第1段階のマップ・部分復活・ポップ版UIはユーザー検収済み。

## 実装範囲

- 基本衣装は全景マップの下の案内エリアに表示。マップ上には重ねない。
- 各施設の仮画面に専用衣装を表示。PCではセリフと横並び、スマートフォンでは画像の下に吹き出しを配置。
- 案内セリフ4種類を依頼文どおりに設定。文字の変更や画像差し替えは `js/config.js` の `guide` に集約。
- 正式PNG4枚を無加工で使用。824×753、RGBA。CSSで縦横比を保ち、耳と衣装を含む全体を表示。
- 読み込み失敗時は破損画像を見せず、準備中の案内を表示。セリフと既存操作は維持。
- 静止画と固定セリフのみ。パズル・正解判定・ヒント・会話送り・衣装切り替え機能・セーブ・エンディング・音声・キャラクターアニメーションは追加なし。

## 確認結果

Windows / Chromium系ブラウザーのローカルHTTPプレビューで確認。

| 項目 | 結果 |
| --- | --- |
| マップの基本衣装と案内セリフ | 正常。マップを遮らない |
| 各施設の専用衣装と指定セリフ（PC・390px幅） | 3施設とも一致 |
| 320・390・768・1280px幅 | 横のはみ出しなし、画像比率824:753を維持 |
| スマートフォンでの顔・耳・衣装 | 切れずに表示、吹き出しの文字も目視確認 |
| マップへ戻る・施設URLの再読み込み | 正常 |
| 復活状態8通り | 正常。0施設は0枚、1/2施設は部分マスク、3施設はマスクなし1枚 |
| リセット | 0施設へ復帰 |
| 基本画像・施設画像がない場合 | 代替の案内、セリフ、移動操作が維持される |
| 欠落画像の施設から正常画像の施設へ移動 | 画像表示が復帰し、代替案内は消える |
| JavaScript構文チェック | 合格 |
| `git diff --check` | 合格 |

前コミットと比較し、復活・リセット処理、全景画像の読み込み処理、画像パス・施設位置・復活範囲が一致することも確認。星うさぎ4枚のSHA-256は作業開始時と終了時で一致。

欠落時の確認には、`test-results/` 内の一時ページから同じアプリコードに欠落パスを与える方法を使用。正式PNGを移動・削除・変更せずに検証し、一時ページは公開・コミットしない。
