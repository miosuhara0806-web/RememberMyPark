## ミニトレインの設計と抜け道検証

表示・判定の方向定義は `js/puzzles.js` に統一：北0、東1、南2、西3。直線は向かい合う2端子、曲線は隣り合う2端子。SVGも同じ `ports()` を参照して端から端への線路を描きます。

正解ルートを設計し、その入退出方向からタイル形状と正解回転を導出。その後、未使用タイルを含む初期回転を設定しています。以下の番号は上から行、左から列の順です。

### 第1問：3×3、星の駅1つ

入口は1行1列の左。出口は3行3列の右。

```text
入口 → (1,1) → (1,2)
                 ↓
       (2,1) ← (2,2) ★星
         ↓
       (3,1) → (3,2) → (3,3) → 出口
```

9マス中7マスを通過。使わない2マスの曲線の向きは自由です。直線の180度対称をまとめた全32,768盤面を検証し、正解は同一の7マス経路に属する16盤面（未使用2カーブの4×4通り）のみでした。

### 第2問：4×4、星と花の駅

入口は1行1列の左。出口は4行4列の右。

```text
(1,1) → (1,2) → (1,3)
                   ↓
(2,1) ← (2,2) ← (2,3)
  ↓      ★星
(3,1)   (3,2) → (3,3)
  ↓      ✿花       ↓
(4,1) → (4,2)   (4,3) → (4,4)
           ↑
       花の駅へ
```

正確な巡回順：1-1 → 1-2 → 1-3 → 2-3 → 2-2（星）→ 2-1 → 3-1 → 4-1 → 4-2 → 3-2（花）→ 3-3 → 4-3 → 4-4。

16マス中13マスを通過。駅の順序条件は判定に含めていません。形状上実現できる全単純経路を探索すると、ゴール到達は次の2本のみです。

1. 上記13マス経路：両駅を通るので正解。
2. 1-1 → 1-2 → 1-3 → 2-3 → 2-4 → 3-4 → 3-3 → 4-3 → 4-4：9マスだが両駅未通過で不正解。

2本目をブラウザーでも実際に回転して作り、「星の駅と花の駅を通っていない」と表示されることを確認。短い経路が正解になる抜け道はありません。答え合わせを連続で押しても追跡番号が重複しません。

各タイルは2端子で分岐しないため、入口からの走行は単純経路か閉路です。全経路探索は、回転で実現できる単純経路を網羅します。追跡処理は進入口の接続、退出方向、隣接マスとの接続、盤外への逸脱、閉路、指定出口、全駅通過を確認。線路の逆走・飛び越しを許可しません。使用しないマスの方向は正解条件に含めません。
