# RememberMyPark
A puzzle game about restoring a forgotten amusement park.

## Remember My Park（リメンバー・マイ・パーク）

星うさぎとパズルを解き、眠っていた遊園地にあかりを戻すブラウザゲーム。
現在は**第4段階・スマートフォン実機検収用の公開版**です。ユーザーによるPCでの最終検収（6問の通しプレイ、3施設復活、エンディング、自動セーブの再読み込み、初期化）は完了しています。**スマートフォン実機の最終検収までは、初版完成扱いにしません。**

HTML / CSS / JavaScriptのみで動作。外部ライブラリ・ビルド・インストール・外部CDNへの接続は不要です。

### 起動と試遊

自動セーブを同じ配信元で使えるよう、HTTPプレビューを推奨します（Node.js 18以上）。`index.html` の直接読み込みでは、ブラウザーにより保存の扱いが異なります。

```powershell
cd C:\Users\user\Documents\RememberMyPark
node scripts/serve.mjs
```

表示された `http://127.0.0.1:4173` を開きます。終了は `Ctrl+C`。別ポートの場合は `$env:PORT = '4174'` を指定してから起動します。サーバーはこのPCのループバックでのみ待ち受けます。

- マップ上か施設一覧から3施設を好きな順で選択。
- 衣装と案内を見て「第1問をはじめる」を押す。
- 各施設で第1問をクリアすると第2問が開放。第2問で施設復活。
- 各問題に「答え合わせ」「やり直す」「ヒント（3段階）」を用意。不正解のペナルティなし。
- マップへ戻る・別施設へ移る・再読み込み・タブを閉じる操作の後も、このブラウザーの進行を復元。
- 開放した問題は施設画面上部で切り替え可能。「やり直す」は今の問題の配置・ヒントを初期化し、開放済みの問題と復活表示は維持。
- 配置変更・回転・ヒント・クリア時にlocalStorageへ自動保存。問題の解放・復活数・エンディング到達も保存します。
- 全施設復活でマップの星うさぎがお祝いし、「エンディングを見る」から進めます。鑑賞後もマップ・施設へ戻り、何度でも再表示できます。
- マップの「最初からやり直す」は確認画面を表示。「やめる」・Escでは記録を維持し、確定時だけ全記録を初期化。
- DEV切り替えは検証用表示のみ。通常の記録・あかりの数・エンディング解放を変えません。「通常の進行表示に戻す」、施設へ移動、再読み込みでプレビューを解除。

### 自動セーブとエンディング

保存キーは `remember-my-park.progress.v1`。各施設の問題番号・開始状態・クリア状態・現在の飾り／色／回転・ヒント段階、施設復活、あかりの数、エンディング到達を保存します。復活状態とあかりの数はクリア記録から算出し、DEVの表示は保存しません。

読み込み時には形式・値の範囲・重複・問題の解放順・クリア時の盤面・復活数の整合を確認。破損データは初期化して案内し、保存禁止や容量不足ではゲームを止めずに保存できない旨を表示します。リセットの保存に失敗したときは、元の記録を消しません。他のlocalStorageキーは変更しません。

保存先はブラウザー・プロフィール・配信元（ホスト／ポート）ごとです。localhostとGitHub Pages、4173と4174の記録は別で、クラウド同期はありません。第3段階までの保存されていなかった進行を、ページ更新後に自動で引き継ぐことはできません。保存は第4段階から有効です。

エンディングは正式な復活後マップを使用し、基本衣装の星うさぎ、指定の本文・お礼、『Remember My Park』『おしまい』を表示。夜景の専用イラストは未配置です。届いたら `js/config.js` の `ending.image` に相対パスを指定するだけで差し替えられます。読み込み失敗時は正式な復活後マップへ戻ります。本文は `ending.paragraphs`、お礼は `ending.message`、全復活後のセリフは `guide.restoredMessage` です。

### 6問

| 施設 | 第1問 | 第2問 |
| --- | --- | --- |
| メリーゴーランド | 木馬たちの忘れもの（4頭・4飾り） | 思い出の飾りを探して（5頭・5飾り） |
| 観覧車 | 眠ったゴンドラ（5色） | 空に浮かぶ6つの色（6色） |
| ミニトレイン | はじめての運行再開（3×3・星の駅） | よりみち駅をめぐろう（4×4・星と花の駅） |

木馬・観覧車は下の選択欄で指定。配置済みの飾り・色を選ぶと、元の配置先と自動交換します。空の欄から選んだ場合は元の配置先が空になります。未配置の候補の選択と、「選ぶ」に戻して空ける操作は従来どおりです。すべて異なるものを配置してから答え合わせができます。観覧車は円形図のゴンドラをタップして該当の選択欄へ移ることもできます。番号と色名を併記しています。

ミニトレインはタイルをタップして時計回りに90度回転。盤面外の入口・出口矢印に合わせ、途中駅を通って線路をつなぎます。**全マス通過不要・駅の順序指定なし**を採用。第1問の正解ルートは7マス、第2問は13マス。入口から実際に接続を追跡し、途中駅を飛ばしたゴール到達は不正解です。答え合わせ時には通過マスを番号付きで表示します。

### 星うさぎと表示

- 正式な透過PNG4枚を無加工で使用。画像の生成・変更なし。
- 開始前は既存の施設別衣装と案内。プレイ中は縮小し、盤面に重ねない配置。
- ヒント・不正解・正解時は短いセリフを表示。一人称は「ぼく」。第2問は復活を祝う星飾りとマップのあかりを連動。
- ピンク／ラベンダー・水色／ミント、丸いボタン、チケット風の枠を維持。
- 正誤は「✓ 正解」「↺ もう少し」等の文字・記号でも表示。キーボードと読み上げ用ラベルに対応。
- 動きを減らすOS設定を尊重。スマートフォン用選択欄は16px文字で、iOSのフォーカス時拡大を抑える設定。
- 画像が読み込めない場合は代替案内を表示し、パズル操作・移動を維持。

### 素材とマップの調整

| 素材 | パス |
| --- | --- |
| 全景・復活前 | `assets/maps/park-before.png` |
| 全景・復活後 | `assets/maps/park-after.png` |
| 星うさぎ・基本衣装 | `assets/characters/star-bunny-base.png` |
| メリーゴーランド衣装 | `assets/characters/star-bunny-carousel.png` |

| ミニトレイン衣装 | `assets/characters/star-bunny-train.png` |

配置済み正式素材を維持しています。画像パス・案内セリフ・タップ領域・復活範囲は `js/config.js`。マップの座標は画像全体に対する百分率です。`hotspot` は中心x/yと幅・高さ、`restoration` は中心x/yと楕円の半径。既存の検収済み座標は変更していません。

全景2枚は同じ構図・縦横比で用意してください。片方が欠落、または縦横比が異なる場合は、揃った仮画像ペア（1440×960）で表示します。正式画像と仮画像は混ぜません。部分復活は前景画像とCSSマスクで重ね、全施設復活でマスクなしの完全画像へ切り替えます。構図自体のずれは自動補正しません。

### ファイル構成

```text
index.html                     マップ・施設・エンディング・確認画面
css/style.css                  PC・スマートフォンの共通UI
js/config.js                   素材・施設・衣装・案内・マップ座標
js/puzzles.js                  6問のデータ・方向定義・正解判定・経路列挙
js/puzzle-ui.js                 盤面・操作・ヒント・進行の保存連携・お祝い
js/save.js                      保存形式・読み書き・復元データの検証
js/app.js                      画面遷移・復活表示・画像読み込み
scripts/serve.mjs              ローカル開発サーバー
scripts/check.mjs              構文・既存パズル・保存の検証を実行
scripts/check-save.mjs         途中再開・クリア・破損22ケース・保存失敗・初期化の検証
scripts/check-puzzles.mjs       全候補・全経路・ヒントの検証
assets/                        検収済み正式画像・仮マップ・ローカルフォント
```

フォントのライセンスは `assets/fonts/OFL.txt`。過去の確認記録は `docs/stage-1-checks.md`、`docs/ui-retake-checks.md`、`docs/star-bunny-checks.md` に保持。キャッシュ対策のURLバージョンは `index.html` の `v=stage-4-1` です。
